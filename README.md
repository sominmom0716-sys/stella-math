# Daily Math Notebook

Stella's daily Grade 5 math practice (Canadian curriculum), built as a single web page.

- 16 questions a day: multiplication, division, fractions, shapes & angles, word problems, explain-your-thinking
- Scratch paper for finger or stylus, hints, step-by-step solutions
- Time limit, skip-for-now, and a monthly stamp calendar

Open `index.html` in a browser, or use the GitHub Pages link. Progress is saved in the browser on each device.
